# Code of Conduct

The Aegis project expects respectful, technically honest, and constructive participation.

- Discuss ideas and evidence without personal attacks.
- Give reproducible examples when challenging behavior or a claim.
- Do not misrepresent test results, authorship, security impact, or implementation status.
- Respect privacy and use the private security channel for vulnerabilities.
- Maintainers may edit, hide, or remove abusive, deceptive, unsafe, or off-topic contributions.

Enforcement concerns may be reported privately to the repository maintainer.
