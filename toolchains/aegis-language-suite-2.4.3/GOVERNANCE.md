# Governance

Aegis uses a maintainer-led model.

The maintainer sets release scope, accepts or rejects changes, assigns compatibility status, and decides when a tested foundation is ready to become a supported feature. Technical decisions are based on documented behavior, reproducible tests, safety impact, maintenance cost, and compatibility with the deterministic execution model.

Discussion and review are welcome through issues and pull requests. A proposal is not accepted merely because an implementation exists; its specification, failure behavior, tests, documentation, and long-term support cost are reviewed together.

Security reports use the private process in [SECURITY.md](SECURITY.md). Community participation follows [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
