# Third-party and clean-room boundary

`vendor/aegis-2.4.0/` is the project's own Aegis Language Suite 2.4.0 lineage, distributed under its bundled MIT terms. It is included so the DXL/DXS/DXASM certificate path can be rebuilt from the strict-C stage-zero source without a download.

Canonical/University of Bristol's announced C-to-Rust work, C2Rust, Cpp2Rust, Kani and Miri were used only as public comparison/research references. No source from those projects is vendored into Aegis-C2R and this prototype is not presented as an implementation of their unpublished work.
